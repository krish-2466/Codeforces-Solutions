## 📖 What Each Solution Includes

Whenever possible, each problem is documented with the following sections:

1. **Problem Statement / Summary** — What the problem asks us to solve.
2. **Approach** — The intuition behind the solution.
3. **Algorithm** — Step-by-step logic.
4. **Example Walkthrough** — How the solution works on sample input.
5. **Java Implementation** — The source code.
6. **Complexity Analysis** — Time and space complexity.
7. **Key Takeaway** — The main concept learned from the problem.

## 🧭 How to Use This Repository

If you are preparing for competitive programming, DSA interviews, or coding assessments:

1. Find a problem using its rating folder.
2. Try solving the problem yourself before viewing the solution.
3. Read the explanation to understand the underlying logic.
4. Study the Java implementation.
5. Analyze the time and space complexity.
6. Revisit the problem later to strengthen your understanding.

**Tip:** Focus on understanding the approach rather than memorizing the code.
